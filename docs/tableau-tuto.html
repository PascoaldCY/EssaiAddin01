Tutoriel Word – Comment réaliser l'exercice

1. Comprendre l’exercice

Avant de commencer, lisez attentivement l’énoncé. Notez :

  • Le type de document attendu (lettre, tableau, formulaire…)
  • Les parties à automatiser ou à formater
  • Les contraintes (police, style, numérotation…)
Astuce : surlignez ou notez les mots-clés pour ne rien oublier.

2. Créer le document

  • Lancez Word et ouvrez un document vierge.
  • Vérifiez la mise en page (orientation, marges, taille du papier).
  • Si le document a plusieurs sections, utilisez Sauts de section.

3. Structurer le document

  • Ajoutez les titres et sous-titres.
  • Créez les paragraphes, tableaux ou listes demandés.
  • Utilisez les styles prédéfinis pour faciliter la navigation et la mise à jour.

4. Ajouter des éléments automatiques

  • Table des matières : Références → Table des matières
  • Champs automatiques : date, nom, numéro de page (Insertion → Quick Parts → Champ)
  • Tableaux et listes structurées via Insertion → Tableau

5. Mise en forme et styles

  • Appliquez polices, couleurs et alignements demandés.
  • Pour un style répété, créez un style personnalisé.
  • Ajustez bordures et largeur de colonnes pour les tableaux.

6. Vérification

  • Relisez chaque section pour vérifier la cohérence avec l’énoncé.
  • Testez les champs automatiques pour vous assurer qu’ils se mettent à jour correctement.
  • Sauvegardez régulièrement votre travail.

7. Astuces rapides

  • Ctrl + T : créer un tableau rapide
  • Ctrl + Maj + N : appliquer le style normal
  • F9 : mettre à jour les champs automatiques
  • Alt + Maj + Flèche : déplacer un paragraphe facilement
