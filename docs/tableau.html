📋 Instructions

🚀 Étape 1 : Initialisation

Cliquez sur "Initialiser l'exercice" pour créer un document Word avec un tableau de base.

🎨 Étape 2 : Personnalisation du tableau

Maintenant que votre document est créé avec un tableau, vous devez :

  • 🎨 Modifier le style du tableau pour créer une mise en page personnalisée
  • 🌈 Ajuster les couleurs, bordures, polices et alignement du texte dans les cellules
  • 📊 Appliquer des bandes alternées pour améliorer la lisibilité
  • 📋 Mettre en forme la ligne d'en-tête pour la distinguer
  • 👁️ S'assurer que le tableau reste lisible et esthétique

💡 Conseils pratiques :

  • Utilisez l'onglet "Création de tableau" dans Word
  • Essayez différents styles prédéfinis avant de personnaliser
  • Pensez à la cohérence des couleurs avec votre document
  • Vérifiez la lisibilité sur différentes tailles d'écran
